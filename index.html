PSA LFS EDUCATIONAL MOBILITY PIPELINE

View on GitHub

My undergraduate thesis studies intergenerational mobility in the Philippines across educational, occupational, and income outcomes. This repository showcases the educational-mobility pipeline and analysis: preparing quarterly PSA Labor Force Survey files, handling changes in survey schemas and education codes, cleaning records, and building parent–child household links for regional Bayesian analysis. The occupational and income components are part of the broader thesis, but are not presented here as completed, reproducible repository workflows.

The Engineering Challenge
PSA used three different column schemas across survey years. The K-12 reform in 2016 created two incompatible grade code systems mid-dataset — the same numeric code means a different education level depending on the quarter. A schema config registry routes each quarterly file to the correct column names and grade mapping automatically. A 12-step cleaning pipeline pairs parents and children within households and logs every run.
Bayesian Model
Multilevel Linear Model via Bambi/PyMC: 4 chains × 2,000 draws, all R-hat < 1.01. Predictors: father's and mother's schooling years (with quadratic terms), children per household, child age, and survey year fixed effects. Region-level random intercepts and slopes allow the effect to vary by region. Prior sensitivity confirmed across 3 specifications.
Scope note
The broader thesis covers educational, occupational, and income mobility. The public repository currently showcases the educational pipeline and analysis only; the other outcome-specific workflows are not presented as reproducible project components here.
